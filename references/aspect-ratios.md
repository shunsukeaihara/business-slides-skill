# 画面比率と再レイアウト

会社のブランドとは別の選択軸。選択したマスタの`profiles`から寸法を読み、1資料内で統一する。同梱マスタは13:9=1040×720、16:9=1280×720。両者は高さを揃え、文字・線幅・アイコン・ロゴのサイズを維持する。出力寸法は幅÷96、高さ÷96inch。

## 比率変更で変えるもの・保つもの

| 要素 | 再配置 |
|---|---|
| タイトル・線・パンチライン | 左右余白を保ち、幅を新しい本文幅にする |
| フッター | 左の文言は左端、ロゴは中央、ページ番号は右端へ再固定 |
| 表紙 | ロゴは右端からの距離、タイトルは左端からの距離で配置。画像比率は維持 |
| 比較グリッド | 列幅を再計算。見出しや本文のサイズは保つ |
| 行見出し＋詳細 | 短い行見出しは一定幅、追加幅は詳細に配分 |
| チャート＋解釈 | 解釈欄に読みやすい幅を確保し、残りをプロットへ。単純な全体拡大はしない |
| 円・バブル・写真 | 縦横比を維持。配置だけ変更 |
| 散布図・時系列 | 新しいプロット領域へデータから再投影。ラベル位置も再計算 |
| 工程・ツリー | 列幅と接続線を再計算。段階数を空白埋めのために増やさない |

## グリッド計算

マスタから本文左端`L`、幅`W`、列間`G`を取得する。

- 等幅n列：`colW=(W-(n-1)*G)/n`、`x[i]=L+i*(colW+G)`。
- 行見出しR＋n列：`colW=(W-R-G*n)/n`、`x[i]=L+R+G+i*(colW+G)`。
- 比較図＋説明：説明欄E=本文幅の約25〜32%を出発点とし、長文なら上限400px前後で改行を確認。図幅=`W-G-E`。
- 行高：本文高から見出し・行間を除き分配。同程度の内容は等高、極端な差は統合や分割で解消。
- 13:9の座標を16:9へ移すとき、`x*=1280/1040`のような一律変換は禁止。フォントや円が歪むCSS `scaleX`も使わない。

幅が広がっても長文を無制限に1行へ伸ばさない。文章幅が余る場合は、領域内中央に適切な幅を設けるか図との配分を変える。意味のない左右空白・短い最終行を画像で確認する。

## 本文幅の選択

比率と本文幅は別の設定。`contentWidth: "standard"`は最大本文幅×`layout.standardBodyRatio`（既定0.88）、`"wide"`は最大本文幅。いずれもX=(スライド幅−本文幅)/2。13:9でも16:9でも左右の余白を等しく保つ。タイトル・パンチライン・フッターはマスタの最大幅を維持する。
