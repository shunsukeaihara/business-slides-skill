# 会社別マスタとパターンの分離

## 管理単位

```
masters/<company>/master.json   色・書体・寸法・表紙・フッター設定
masters/<company>/master.md     その会社の視覚仕様・例外
masters/<company>/assets/       ロゴ等、その会社だけの素材
references/layouts-and-charts.md / advanced-layouts.md  汎用構成
scripts/build_html.mjs          データ＋マスタからHTMLを組む
assets/pattern-examples.json    業務に依存しない例示データ
```

パターンのデータに会社ロゴ・社名・色コード・書体を埋め込まない。マスタに案件名・実績・顧客・具体的な役割を埋め込まない。出力HTMLはマスタを解決した成果物であり、編集元はマスタとデータ。

## マスタの項目

`masters/neutral/master.json`が完全な設定例。別会社はそのフォルダを複製し、設定とロゴを差し替える。汎用マスタの原本は保持する。

| キー | 内容 |
|---|---|
| `id`, `name` | 会社マスタの識別と名称 |
| `profiles` | `13:9`, `16:9`の幅・高さ。現行補助処理は1040×720／1280×720 |
| `colors` | 背景、本文、表紙文字、アクセント、面、補助文字、線、タイトル線、フッター線、系列色配列 |
| `fonts` | 英文書体、日本語書体、フォールバック |
| `type` | 表紙、タイトル、パンチライン、見出し、本文、高密度本文、注記、フッターのサイズ |
| `layout` | 横余白、タイトルと線、本文、フッターのY座標、列間、箱内余白、標準本文幅の比率`standardBodyRatio` |
| `cover` | ロゴの右余白・寸法・Y、区切り線、タイトル・副題の配置 |
| `brand` | ロゴの相対パスまたはnull、フッター文言、ロゴ寸法・Y、ページ番号の有無 |

`colors.series`は量的系列の識別に使用し、優劣の意味を自動付与しない。ロゴパスはマスタのJSONのあるディレクトリからの相対参照。未提供のロゴを他社のもので代用しない。

表紙構図まで大きく異なる会社では、マスタの数値だけで無理に合わせず、専用の表紙実装を追加する。その場合も本文パターンは変更しない。任意の外部PPTXマスタを自動取り込みする機能ではない。

## 使用例

```sh
node SKILL_DIR/scripts/build_html.mjs --master SKILL_DIR/masters/neutral/master.json --aspect 16:9 --data SKILL_DIR/assets/pattern-examples.json --out WORK_DIR/wide.html
```

`--aspect 13:9`なら標準版。`--master OTHER_MASTER/master.json`で別会社へ切り替える。出力先にロゴと検査用JSを同梱する。会社別マスタごとに別の出力フォルダを使う。出力ロゴの名前は`brand-coverLogo`／`brand-footerLogo`で、同じフォルダで混在させない。許可された上書きに限り`--overwrite`を指定する。

同梱パターンは出発点。内容の関係が異なる場合は、無理にデータを当てはめずHTMLを作り替える。その際も色・書体等はマスタ由来のCSS変数、本文領域は共通座標から取得する。

## 同梱見本のロゴ

スキル直下のassetsにあるブランド画像とギャラリーは汎用マスタの仮ロゴを使用する。会社固有の素材は、公開対象と分離した会社別マスタで管理する。会社別マスタを適用して資料を生成するときは、その資料の出力ディレクトリへ生成し、共通assetsの見本を会社ロゴで上書きしない。

## 左右の外側余白

`profiles[aspect].marginX`で比率ごとの左右余白を指定する。未指定なら`layout.marginX`を使用する。同梱マスタは13:9で32.4px、16:9で34.8px（従来の22pxから左右それぞれ画面幅の1%を追加）。タイトル・パンチライン・本文最大幅を同じ外側境界内に収める。標準本文はその最大幅の88%、ワイド本文は100%とし、いずれも全体を横中央に配置する。表紙の配置は`cover`で独立管理する。
